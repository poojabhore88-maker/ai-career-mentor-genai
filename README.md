# AI Career Mentor & Interview Simulator

An AI-powered platform that generates personalized career roadmaps and conducts role-specific interview simulations using Generative AI.

## 🚀 Features
- Resume upload (PDF/DOCX/TXT)
- AI-generated career roadmap
- Role-based mock interview questions
- Real-time AI interview feedback

## 🧠 GenAI Usage
- Resume understanding using LLMs
- Personalized roadmap generation
- Interview answer evaluation

## 🛠 Tech Stack
- Python
- Streamlit
- OpenAI / Azure OpenAI
- PDF & DOCX parsing

## ▶️ Run Locally
```bash
pip install -r requirements.txt
python -m streamlit run app.py
